用途：用不同输入和失败形态验证 Planner → Tester → Developer → Go 检查 → Gate。每个任务是独立的标准库 Go CLI，保持 3–6 个文件、无外部依赖。模型自写测试不是唯一的业务证据；关键边界另写独立探针。具体运行结果见 本轮进展。

## S1：整数求和

Go 标准库 CLI，命令行参数为十进制整数，输出所有整数之和并换行。无参数输出 `0`。允许负数。任何非法参数打印错误到 stderr、退出码 2、stdout 为空。逻辑函数和 CLI 行为都要有测试；不扩展为大整数计算器。

## S2：文本行统计

Go 标准库 CLI `linecount PATH`，读取 UTF-8 文件，输出十进制逻辑行数并换行。空文件为 0；末尾换行不增加额外空行；LF 与 CRLF 等价；文件仅包含一个换行算 1 行。参数数量错误、文件不存在、非法 UTF-8 时 stderr 给出错误、退出码 2、stdout 为空。使用 `t.TempDir` 做 CLI 测试。

## S3：JSON 配置校验

Go 标准库 CLI `configcheck PATH`。文件只能包含 JSON 对象字段 `host`（字符串，可省略，省略时为 `localhost`）和 `port`（必填整数，1..65535）；未知字段、重复字段、其他类型、空 host、尾随额外 JSON 值都应报错。成功时 stdout 只输出单行规范 JSON，字段顺序固定为 host、port，后接换行；失败时 stderr 非空、退出码 2、stdout 为空。

## S4：CSV 费用合计

参见 [已有费用场景](SCENARIO_CSV_EXPENSE.md)。可先简化为 `category,amount_cents` 两列、最多 100 行；重复类别求和并按类别名排序。带引号的逗号属于类别内容，非法行返回错误且 stdout 不输出半份结果。全程使用整数分，不能使用浮点。用真实临时文件测试 CLI。本轮未运行。

## S5：区间归并

Go 标准库 CLI，输入参数为若干 `start:end` 整数区间，输出按起点升序归并后的区间，每行一个 `start:end`。闭区间相交或相邻时合并，例如 `1:3 4:5` 得 `1:5`；负数也遵循相同规则。无参数输出空内容并退出 0。非法整数、缺少分隔符、start 大于 end 时 stderr 非空、stdout 为空、退出码 2。测试排序、嵌套、相邻、负数、最大整数边界和非法输入。
