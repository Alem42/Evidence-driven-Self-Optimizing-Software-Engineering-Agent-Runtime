# 可选硬件面板方案

可行，但暂不实施，也不申请管理员权限。

第一步展示已有 Ollama ps：模型实际显存占用、加载上下文、总模型内存。这已经能解释部分 CPU/GPU 混合运行；不能推算整机物理显存容量或内存频率。

第二步添加只读宿主机采集器：优先通过 nvidia-smi 查询 GPU 名称、总/已用/空闲显存；Windows 通过 CIM 查询整机内存和内存条容量、标称/配置频率。单位明确，不把磁盘大小、模型占用和硬件容量混用。不同驱动或设备可能缺字段，缺失显示未知。

采用固定参数的白名单命令，短超时、输出限制、低频缓存，不提供任意命令输入。不为采集失败提权；无 NVIDIA 工具、权限不足或非Windows时降级。硬件结果作为本机监控数据，不默认传给 LLM。

第三步在控制页折叠展示硬件信息。先验证字段单位与刷新成本，再考虑温度/功耗/利用率；不做自动超频、驱动修改或设备配置。是否适合某模型以实际加载与任务表现为准，不仅看参数量。
