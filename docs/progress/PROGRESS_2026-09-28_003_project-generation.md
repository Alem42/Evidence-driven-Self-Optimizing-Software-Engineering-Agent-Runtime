# 本轮进展：确认需求后生成整套代码

2026-09-28。

## 如何使用

在已确认项目方案中点击“根据已确认方案生成代码”，选择有密钥的 API。Developer 提交全部批准路径的代码草稿。用文件下拉框逐个查看/修改实现与测试，点击“批准整套代码并验证”。

批准后自动创建 .masa/workspaces/<执行 run ID> 项目文件夹并运行 test/vet/格式检查。结果页显示路径、日志与状态。当前不会启动 CLI 程序本身，go run 属于下一阶段。

## 关键实现

- 只接受已确认的规格；文件集合必须严格匹配目录，禁止额外文件/外部依赖声明。
- 草稿只存 artifact，人审前没有实现代码落盘到可执行项目。
- 整套文件准备完再发布 Runtime 快照；批准内容与实际快照哈希绑定。
- 同一批准内容重试复用执行记录；不能在旧批准上更换内容。旧方案、草稿与执行是关联的独立记录。
- 继续复用现有 Runtime、SQLite、Go runner，没有新增服务或调度平台。
