## 当前限制与下一步

这是完整角色 Runtime 的中间增量，尚不是任意角色 DAG 的统一恢复调度器。自动修复分支仍拒绝自动重放；可以恢复已落盘修复草稿，但自动流程检查点的连接仍需补齐。未知网络请求不能保证外部服务 exactly-once。

下一步优先解决：修复/测试修订自动检查点、发布后检查点写入前的崩溃窗口、重复断言计数持久化；再统一角色 Step/Attempt 和前端恢复入口。然后用既有随机数、求和、行数统计和 JSON 配置案例做跨阶段恢复矩阵。

修复上下文的 32KB 限额只约束 ContextBuilder 检索片段，不等于最终模型提示的硬上限。此次小随机数项目所有文件都被保留，不能宣称降低 token。独立测试审查、变异测试、跨任务经验学习和任意项目依赖安装尚未完成。
