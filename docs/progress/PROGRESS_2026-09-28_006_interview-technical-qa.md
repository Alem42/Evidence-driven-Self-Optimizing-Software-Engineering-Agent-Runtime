# 面试技术问答整理

本轮根据用户附件中的 20 个问题，生成 [面试技术说明](../archive/guides/USER_INTERVIEW_TECHNICAL_QA.md)，覆盖 Runtime、图变更、Gate、证据与快照、记忆、上下文、Go 执行层和自优化。

核对了当前源码与最新接续记录，将代码事实、可落地设计和远期愿景分别标注。尤其补充了失败节点如何触发修复、旧失败如何保留而不污染新轮验收、集合类记忆为何受新增文件影响，以及工具执行后记账前崩溃的恢复边界。

按用户后续要求进一步收紧为一周增量：日志提取、文件级记忆有效性、两种有界补证、关联草稿修复及回归验收。删除运行中改图和自优化的复杂实施方案；这些问题只说明暂不实施。并发增量索引单独后置，不与本周工作叠加承诺。

本轮只修改文档，没有实现 GraphPatch、增量索引或自优化，没有调用付费模型或运行业务测试。验证范围是 Markdown 链接、20 问覆盖和 Git 差异检查。

产品下一步保持前端固定入口 go run，不因面试说明改变实施优先级。文中的阈值和 JSON 示例是设计建议，不是运行数据；Windows 进程约束不代表 Linux 已支持或具备完整沙箱。
