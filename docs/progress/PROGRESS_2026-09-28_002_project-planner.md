# 本轮进展：Planner 主导项目结构

2026-09-28。按用户重点完成 B2，并补齐最小 B1 契约与 B3 前端审核。

## 新能力

前端增加“规划新项目”：自然语言需求 → Planner 架构提案 → Tester 验证方案 → Runtime 校验 → 人工确认。Planner 给出设计理由、Go 模块、固定入口、文件职责和具体验收项；Tester 只读取校验后的规格，不修改架构，也不运行测试。

沿用现有 run/artifact/event 与预算，没有新增数据库或调度平台。两次调用分别记录上下文、响应、用量；响应不合格或调用失败即停止，不自动重试。前端支持预览和编辑方案，确认后冻结审批 artifact。Runtime 编译固定允许的检查图，Gate 覆盖三个真实检查。

规划记录禁止 resume/rerun 执行，占位 Go 模块不能被误认为生成好的项目。完整多文件代码生成尚未实现。
