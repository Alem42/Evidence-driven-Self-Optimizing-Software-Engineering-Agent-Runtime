# 让测试更可靠：测量与结论（只测量，还没有接进流程）

2026-10-07。数据与完整表格见 [reference/TEST_RELIABILITY](../reference/TEST_RELIABILITY.md)（每任务的难度、耗时、token、费用、期望准确率）。总花费 ≈ ¥1.1（API，并行；两个测量各 184 次调用，每次 1–3 秒）。

## 做了什么
- 两个新的**数据角色**（RoleSpec，无需 Python 校验器）：`expectation_deriver`（只给输入，独立推导期望的 stdout/退出码）、`expectation_auditor`（给声明的期望，判断对不对）。
- `scripts/eval/expectation_accuracy.py`：对评测题库 23 个任务的固定输入，让 Flash×5、Pro×3 并行推导期望，与独立的 Python 参考实现逐用例比对；算单次准确率、多数表决后的准确率与覆盖率、耗时、token、费用。
- `scripts/eval/expectation_audit.py`：把正确的期望一半原样、一半故意改错（数字加一、交换两行、改大小写、改退出码），看各种方法能抓到多少、误报多少。
- `scripts/eval/task_table.py`：把真实运行（默认流程）的通过率、轮数、耗时、token、费用与“期望准确率”并排。
- `application/checks/consensus.py`：盲推导 + 严格多数表决 + 机械比较的确定性骨架（模型调用由调用方注入；并行；失败的样本只是少一票），带测试。

## 测到了什么
1. **便宜的多数表决胜过贵的单次**：单次推导准确率 Flash 78%、Pro 76%（Pro 并不更准）；Flash×3 多数表决 92%（弃权的用例不计）、Flash×5 90%、Pro×3 89%。Flash 单价约为 Pro 的 1/9，每次约 ¥0.0008、1 秒，可并行。
2. **“这个期望对不对？”几乎问不出来，但“你自己算，我再比较”可以**：直接问审计者，召回只有 26–33%、误报 12–22%（被声明的期望**锚定**——和 Diagnoser 被测试带偏是同一个现象）；把声明的期望藏起来，让它盲推导，再机械比较：Flash×3 召回 **91%**、误报 **8%**、改对 84%。
3. **难度可以量化**：期望准确率低且样本之间不一致的任务（lru 44%、topo 60%、calc 67%、regex 17%、kvtx 0%）测试最难写对；kvtx 两个模型全错，更像是**题面本身有歧义**，而不是模型算错。真实运行里难度高的 wc（0.27）、csv_sum（0.25）、knap（0.25）平均 2–2.8 轮、¥0.2–0.4，低难度的 sum/fizz 一轮、¥0.07。
4. 对 best-of-N 的含义：实现有 Gate 这个独立裁判，所以“多采样 + 验证选择”可行；**期望没有裁判，多数表决就是裁判**——这是更适合“测试”的 best-of-N，而且天然并行。

## 局限（不要夸大）
- 测的是**题库的固定输入**与简单的逐字比较，不是流水线里 Tester 实际写出的自由文本用例；Tester 用例的 `expected` 是自由文本（如“Count returns lines=1, words=2, bytes=12”），不能直接机械比较。
- 故意改错的方式有限（数字、行序、大小写、退出码），真实的错误更隐蔽。
- 表决的弃权率（没有严格多数）约 10–20%，生产里这些用例只能丢弃或交给更强的模型。
- 样本很小，kvtx 等任务只有 2 个用例。

## 怎么接进流程（需要你选）
- **A. Tester 用例审计**：规划阶段 Tester 产出用例后，让 Flash×3 并行盲推导这些用例的输入，再用一个“等价判断”把推导结果与 Tester 的自由文本期望比较（判断两段文字是否描述同一个可观察结果；这一步容易、没有锚定问题，但**还没测可靠性**）；不一致的用例替换或丢弃。成本低（每任务约 ¥0.01），改动只在规划阶段。
- **B. 失败时给 Diagnoser 独立证据**：断言失败时对失败的输入做盲推导投票，把“多数认为正确输出是 X”作为证据交给 Diagnoser，避免它被测试带偏。需要先把失败断言里的输入结构化出来。
- **C. 独立的端到端 CLI 检查**（路线图里的“Gate 自己执行产物的 CLI 用例”）：用盲推导多数作为期望，在沙箱里真的构建并运行产物，与生成的测试**互不依赖**地交叉验证。最强也最贵：要给 runner 增加“运行已构建程序”的受限操作。
我的建议：先做 **A**（成本最低，且先用同样的“故意改错”方法测量等价判断的可靠性，达标再接入），之后再做 **C**。
