# 本地模型控制页

重启 MASA，打开顶部「本地模型」或左侧「本地模型控制」。当前固定连接 `127.0.0.1:11434`。

可以刷新已安装/已加载模型，查看文件大小、参数规模、量化、权重摘要、模型信息与加载上下文；加载/释放模型；选为项目默认；执行一次真实协议测速。切换只影响新任务，旧任务继续使用保存的快照。新注册模型默认本地L1、上下文16384、输出8192、超时600秒、关闭思考，可以在模型设置中调整。

磁盘文件大小不是显存占用。页面分别显示 Ollama `list` 和 `ps` 对应数据，实际显存大小未知时显示未知。GLM目前文件约17.7 GiB，不代表需要同样大小的GPU显存。

测速与角色调用保存实际 token 数、总耗时、加载耗时、提示处理耗时和生成耗时。生成速率=`eval_count / (eval_duration / 1e9)`，与 verbose 使用同源计数。当前非流式响应：请求期间仅显示经过时间，调用结束后显示真实速率；不能把最近一次速率当成当前瞬时吞吐。

项目顶部状态条始终显示阶段、模型、任务经过时间与最近一次完成调用速度。浏览历史时后台任务仍保留自己的状态，不自动换模型。运行项目时加载/释放/测速/切换按钮禁用，后端也拒绝并行操作。其他应用或终端对 Ollama 的操作仍不在 MASA 控制范围内。

目前对应 `list / ps / show / run --verbose / stop` 的核心功能；使用官方接口，不执行任意 shell。尚无下载、删除、复制模型、服务启动停止和自由聊天终端。长请求失败不自动重发；先看记录再明确重试。

本轮优先纯本地任务，API与复杂多模型路线暂停推进；现有云端配置保留，不自动回退到云端。
