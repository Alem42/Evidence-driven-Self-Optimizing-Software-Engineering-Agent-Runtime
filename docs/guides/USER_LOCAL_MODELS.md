# 使用本地模型

2026-10-03。当前已支持固定选择本地或 API 模型，尚不会失败后自动升级。

1. 启动 Ollama，确保模型已下载。当前本机检测到 `gemma4:12b`。
2. 重启 MASA 服务，打开侧栏「API 与模型」，添加本地配置。
3. 类型选本地，协议选 Ollama 原生，地址填 `http://127.0.0.1:11434`，模型填完整 tag。无需 API Key。
4. 推荐初始参数：等级 1、优先级 0、上下文 8192、输出上限 4096、超时 180 秒、关闭思考。参数可按模型和机器表现调整；不是性能保证。
5. 保存后「测试连接」，这会真实调用一次模型。随后在新项目中选择该模型。

云端配置默认等级 2，继续使用已有 API Key。可以添加多个本地或云端配置；等级越大表示你指定它能力更强，同等级优先级越小越优先。当前排序方便管理，**不会自动触发升级**。不选择角色表示允许全部；限制角色后，不匹配的调用会拒绝。

本地无需网络计费，但长任务仍消耗机器时间。连接成功只说明接口可用，不代表完整项目生成一定成功。现在仍使用完整 JSON 响应，不是逐 token 代码流。Ollama 原生地址不要加 `/v1`；使用兼容协议时通常需要 `/v1`。

新自动任务和角色请求已保存固定配置快照：恢复沿用原模型和参数；修改当前配置不会悄悄换模型。删除、禁用或改目的地址会明确停止恢复，凭据不会转移到别的地址。旧无快照任务仍依赖原配置。尚未锁定本地模型 tag 对应的权重 digest，修改同名权重需谨慎。完整路线见 多模型计划。
