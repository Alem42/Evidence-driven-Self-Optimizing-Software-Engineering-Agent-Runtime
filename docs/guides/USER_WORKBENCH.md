# 使用工作台

在仓库根目录启动（先关闭旧服务）：

```powershell
.\.venv\Scripts\python.exe -m masa ui --port 8765 --open
```

1. 左下「API 与模型设置」添加配置与密钥，可选择本地保存。
2. 「新建项目」后，在底部选择模型、输入需求，点击开始。
3. 默认逐步确认方案和代码。勾选自动验证时自动采用有效草稿、执行检查，最多修复四轮；会调用真实 API。
4. 中央看方案或文件；顶部看当前阶段，展开阶段记录可跳到对应版本。
5. 通过后展开「运行这个程序」，每行一个参数。也可打开代码文件夹、重新验证。
6. 展开「版本记录与执行日志」查看历史、读取和复制日志。失败证据保留。

Tester 设计测试方案，不在生成前运行测试。Developer 生成代码和测试。Executor 才执行 Go test/vet/格式检查；Gate 不调用模型，独立核对工具结果。通过不代表未覆盖的业务行为一定正确。

底部输入始终显示，当前项目和运行期间禁用新需求提交；需要澄清时中央显示问题。追加需求和真正流式代码预览仍是后续功能。当前完整响应经过校验才显示代码。

常用验收：`python scripts/evaluate_seeded_random.py` 使用配置的真实 API；`--run RUN_ID` 只复验成功项目。运行日志和快照保存在 Git 忽略的 .masa。UI 改动需在 frontend 运行 npm run build 并重启服务。浏览器视觉验收仍待可用浏览器环境。
