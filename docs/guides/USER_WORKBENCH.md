# 使用工作台

在仓库根目录启动（先关闭旧服务，再刷新浏览器）：

```powershell
.\.venv\Scripts\python.exe -m masa ui --port 8765 --open
```

1. 本地优先：点击「本地模型」查看 Ollama 并选默认；云端在「模型设置」添加 API。测速/连接测试会真实调用选定模型。
2. 「新建项目」填写需求、选择模型与执行方式，点击开始。
3. 「当前任务」回答问题、确认方案、编辑和批准代码；失败时修复，通过后可输入参数运行程序。
4. 「代码」按文件阅读草稿或批准快照；「验证」查看真实检查；「日志与版本」复制日志和查看旧版本。
5. 右侧看角色状态和原始需求。主动选历史后系统不抢回页面；用「返回执行中的项目」恢复跟随。

逐步模式分别确认方案和代码；自动模式采用有效草稿并最多修复四轮。Tester先设计测试，Executor才执行Go检查，Gate核对真实证据。模型阶段失败不意味着已经运行测试。

已有项目不显示无效的聊天输入框。追加需求与真正流式预览是后续能力。界面仅在完整响应校验后显示代码。

复验已有随机数版本：`.venv/Scripts/python.exe scripts/evaluate_seeded_random.py --run 77604ca3e7184958938a421da76c4978` 不调用模型。生成脚本会调用指定 profile 或当前默认模型，请显式选择，不把它当成免费离线测试。新布局的浏览器视觉/点击待验证。
