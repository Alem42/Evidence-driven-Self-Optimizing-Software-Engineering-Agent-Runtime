# 从需求到完整 Go 项目

打开 http://127.0.0.1:8765 并刷新。API 管理支持“本地持久保存密钥”；启用后重启自动加载，不需要再次输入。密钥保存在 .masa/provider-keys.local.json，Git 忽略，不通过接口回显。

1. 点击“规划新项目”，描述用途、输入输出和边界。
2. Planner 生成项目结构与验收项，Tester 提出验证方案。预览/修改后确认。
3. 点击“根据已确认方案生成代码”，Developer 一次生成全部批准路径的文件。
4. 在文件下拉框中逐个检查代码与测试，可编辑内容。
5. 点击“批准整套代码并验证”。系统创建独立项目文件夹，执行 test/vet/格式检查。
6. 在运行结果查看项目路径和日志；后续可以一键重验，不再调用模型。

前端暂未提供程序启动按钮。项目目前是标准库 Go CLI，最多 20 文件；复杂需求可能超过单次模型输出上限。建议先使用小型清晰需求。

规划和草稿都不是测试成功。模型自己写的测试不替代独立业务验收；Gate 只依据真实工具结果。未批准的本地编辑不会自动保存，已经批准的内容不能直接改写。
