# P1-01 Go Todo 任务契约

示例位于 `examples/go-todo`，仅使用标准库，是单线程内存服务，无 HTTP、数据库或登录依赖。源代码有意保留两个关联缺陷，公开测试在修复前应失败。

## 修复目标

1. `NormalizeTitle` 去除标题首尾空白（使用 Go 标准库空白语义）。
2. `Service.Create` 必须先规范化，再校验；空白标题返回 `ErrEmptyTitle`，不消耗 ID、不添加记录。
3. 保存规范化标题；成功记录 ID 从 1 连续增长。
4. `List` 返回副本，调用者修改返回值不影响内部数据。

修改范围仅 `todo/item.go`、`todo/service.go`；不修改公开测试、go.mod 或源仓库。修复产物生成在 run 副本，通过真实 `go test ./...` 验证。本例测试是公开契约，不属于隐藏评估；完整外部评估在 P1-08 实现。

## 代码阅读顺序

`item.go` 定义数据和纯函数 → `service.go` 组合校验及状态变更 → `service_test.go` 表达可观察行为。函数说明采用中英文对照。下一任务 P1-02 可用这些声明、调用和测试关联验证 AST 索引。
