## 直接使用

1. 点击右上角「用需求生成代码」，选择有密钥的 API。
2. 输入需求，例如：`实现 Clamp(value, min, max int) (int, error)，把 value 限制在闭区间，min 大于 max 时返回错误，添加中英文函数说明。`
3. 仓库路径留空，会创建一个新的 Go 示例项目，生成 `solution.go`。也可填写已有仓库和一个已存在的 Go 实现文件路径。
4. 点击生成，模型返回后会停在审核页面。可以查看原代码、直接编辑新代码、拒绝，或补充需求重新生成。
5. 点击「批准并写入，然后自动验证」，才会写入隔离副本并执行 `go test`、`go vet`、格式检查与 Gate。源仓库不变。
6. 查看工具证据和最终状态，点击「下载当前代码」取走文件。页面也显示工作副本的绝对路径。

支持一个 Go 实现文件、标准库场景。已有仓库的目标文件必须已存在且不是 `_test.go`。新项目可以在表单中粘贴自己的验收测试，package 为 `solution`；没有测试时，编译通过不代表业务需求已经正确实现。

生成阶段只调用一次真实模型；批准后的验证使用确定性 scripted 决策和真实 Go 工具，不再花模型额度。典型成功记录显示 7 次 model_calls：1 次真实生成 + 6 次离线验证决策；工具次数 4：一次受控补丁 + 三项 Go 检查。
