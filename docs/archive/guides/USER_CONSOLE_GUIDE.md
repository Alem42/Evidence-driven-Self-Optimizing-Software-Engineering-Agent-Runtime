# MASA 浏览器控制台

2026-09-28：主界面已分为「运行结果」「代码与审核」「执行过程」。先选择或生成任务，再审核、查看实际输出；完整图和原始证据在执行过程。已结束的审核有效代码可一键重新验证，新记录保留来源；当前不提供 go run 应用启动。密钥重启后需重新输入。长期路线见 [项目路线](../../PLAN_PRIORITY_ROADMAP.md)。

现在可以用 React 控制台运行和观察 P0 runtime。页面展示来自 SQLite 和 artifact 的真实记录，默认每秒刷新。

## 启动

在项目根目录执行：

```powershell
.venv\Scripts\python.exe -m masa ui --open
```

浏览器地址为 `http://127.0.0.1:8765`。端口冲突时使用 `ui --port 8766 --open`。终端保持运行；Ctrl+C 关闭服务并请求取消此服务正在执行的任务。

已提交构建后的前端，日常启动不需要 Node。修改前端源码后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-ui.ps1
```

此脚本通过 `npm ci` 使用锁文件安装依赖并构建。Go runner 尚未构建时先运行 `scripts/build.ps1`。

## 使用步骤

1. 点击「新建任务」，填写 Go 仓库路径和需求。默认路径是项目自带的 Go 示例。
2. 选择测试、静态检查或格式检查，点击「启动任务」。源仓库保持不变，在独立副本执行。
3. 图中可以查看节点状态、点击节点筛选事件。默认图为 `verify → gate`，不是尚未实现的多 Agent 图。
4. 默认自动继续。可在创建任务时关闭，首个节点后暂停；图上「继续时自动推进」切换后续单步/自动执行。运行中的「暂停」在当前节点结束后生效；「取消」请求停止工具。
5. 「Agent 决策」展示所选 scripted 或真实模型的请求、路由、结构化响应；引用按钮打开上下文与输出。「工具证据」可查看请求、stdout、stderr、退出状态等。
6. 「运行详情」展示预算、快照、工作区、图和 attempt。「查看报告」打开已有运行报告。

## 人工修改需求

任务暂停或结束后，可点击「修改需求」。当前实现重新从源仓库创建一个关联任务，保留旧目标、快照和证据，并记录 `parent_run_id` 与变更事件。旧暂停任务仍可独立查看、继续或取消。

不会在执行途中直接改写旧图。P0 的自然语言需求用于记录目标，执行行为由所选 Go 检查决定，尚不支持根据需求生成代码。运行总时限默认 30 分钟，暂停时间也计入；超时后请创建新任务。

## API 配置

「API 设置」可填写名称、Base URL、模型和 API Key。名称、URL、模型保存在状态目录的 `provider.json`；密钥仅保留在当前服务进程内存，不写磁盘，也不在接口响应中返回。关闭服务后需重新输入；留空保留原密钥，可显式清除。

已接入真实模型，可管理多组配置、选择默认、删除及测试连接。保存配置不等于 API 连接验证；创建任务明确选择 Live LLM 才会调用真实模型。具体参数和已执行的 DeepSeek 验收见 [USER_LIVE_LLM_GUIDE](USER_LIVE_LLM_GUIDE.md)。

## 当前范围

- 单个服务同时执行一个任务，运行记录保留最近 100 条列表，详情展示最近 500 条事件。
- 工具运行中展示状态；完整 stdout/stderr 在工具结束并落盘后可查看，尚无逐行流式日志。
- 控制台未接入代码修改、多角色协作和动态重规划；已记录真实 token 用量，货币费用未知时保持 null。完整验证图可执行 test、vet、format，三个 Agent 节点当前使用同一个模型。
- 控制台只绑定本机回环地址，使用 Host/Origin 校验和会话 token，不作为公网服务部署。
- 本轮构建和 HTTP 自动测试已通过；当前自动化环境没有可用浏览器，视觉及点击验收尚未执行。
