# P2 指挥者的真实对照评测 / Real A/B evaluation of the conductor

2026-10-06。目的：判断动态角色（指挥者 + 测试怀疑者 + 代码审阅者）是否**真的起作用**。结论先说：**没有看到收益，方向偏负；所以保持默认关闭。** 样本很小，下面逐项写明限制。

## 怎么测的
- 模型分工：最上位（规划、测试、诊断、指挥者、怀疑者、审阅者）用 `deepseek-v4-pro`；耗 token 的生成与修复由 `deepseek-flash` 完成（路由器从最低等级起步）。本地模型全部关闭。价格按保守值估算（Pro 9/27 元每百万 token——官方高峰价；Flash 1/4），仅用于费用上限。
- 任务：从评测题库 L2–L5 随机抽（seed 7：roman、fizz、wordfreq、sum、csv_sum、wc、knap、lcs），先跑 8 题，再对出现修复轮的题（wc、csv_sum、wordfreq、lcs）补跑。同一任务“关/开”各一次，交替先后；独立判官复核。
- 费用：总计 **¥8.02**（含 4 次因下面的流式缺陷作废的运行，约 ¥0.25）；硬上限 ¥10，单次 ¥1.2。脚本 `scripts/p2_eval.py`，设置副本在 `.masa/p2eval/`（不动你的设置），原始数据 `summary.json` 与每次运行的账本都保留。
- 三个版本的“开”：**v1**（首轮归属不明就问，候选含 halt）→ **v2**（去掉 halt，reason 只截断）→ **v3**（只在补丁停滞/同一失败重复时才问）。每次改动都来自上一轮的真实现象，见下。

指挥者**真的被调用过**的 7 次运行里：csv_sum（失败）、knap（通过）、lcs（通过）、wc ×3（失败、通过、失败）、wordfreq（因单任务 token 上限停止）——3/7 通过；同样的任务在“关”组里 6/7 通过（唯一失败是 wordfreq 一次）。其余“开”组运行里指挥者没有触发（一轮就过），与“关”的差别只是随机波动与审阅者。

## 我的判断（诚实版）
- **没有证据表明动态角色提高通过率；有证据表明它多花钱**（每次 +24%～+96%，主要来自 Pro 的决策调用、怀疑者、审阅者，以及更早触到单任务 token 上限）。
- 样本太小（每组 3–11 次），一次随机失败（wordfreq 关组 round 2 也失败）就能改变比例；**不能**据此断言“指挥者有害”，只能说：这个设计在这批低等级任务上没有显示价值，也没有理由改默认。
- 原因的推测（**未验证**）：低等级任务的失败大多是“测试期望算错 / 实现小错”，规则 + Diagnoser 已经够用；指挥者的选择经常和规则一样（选 diagnose / repair），而 skeptic 只是复述 Diagnoser 的工作（wc 里 skeptic 判“测试没问题”，随后继续修实现，仍未解决）。

## 评测里发现并修复的真实问题
1. **流式响应上限计原始 SSE 字节**（与指挥者无关，影响所有云端调用）：DeepSeek 每个 token 一个 SSE 块、约 250 字节外壳，1 MB 只够约 4000 token，较长的生成被报 `model response exceeds byte limit`（首轮 7 次里 2 次，共 4 次运行作废）。改为限制解码后的内容（100 万字符）+ 原始 16 MB 安全线；回归测试在旧限制下失败、新限制下通过。
2. **指挥者的 `reason` 超过 200 字时整条提议被拒绝**（选择本身合法）：改为只截断（schema 里留 1000 字防滥用）。
3. **指挥者选了 `halt`，任务被它自己终止**（wc，规则路径历史上 3/4 通过）：`halt` 不再是候选——停止属于确定性规则（stuck_after、轮数上限、预算），指挥者只能选路，不能放弃。
4. **首轮“归属不明”几乎每个任务都出现**，指挥者在那里选的和规则一样（diagnose），白花一次 Pro 调用：改为只在补丁停滞或同一失败签名重复时才问。
5. 评测运行器新增费用上限（`total_cost`、`per_run_cost`）和 `keep_state`（对照评测要事后翻账本）；评测记录新增每次运行的 `cost`。

## 路线分歧（需要你选，见对话）
- **A. 保持“实验功能，默认关闭”（我推荐）**：代码、前端展示、评测工具都保留；README/简历里如实写“已实现并真实评测过，未见收益，因此默认关闭”。这本身是合格的工程结论（设计原则 4：评测决定是否启用）。
- **B. 改成“顾问模式”再测一轮**：指挥者只写 `brief`（给修复角色的提示），**不选路**，路由仍由规则决定。风险小，成本也低，但需要再花约 ¥3–5 才能得到同样粗糙的结论。
- **C. 去掉指挥者，只保留 RoleSpec 与调优器**：减少维护面。
